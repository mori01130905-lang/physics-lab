# 物理 · 刷题室

一个为**平板手写作答**设计的大学物理刷题工具。按章节练习、自动记录进度、AI 批改、错题重刷、知识点讲解和薄弱点总结都放在一个页面里，不需要安装 App，也不需要账号。

当前已把文件夹里的 **2026 秋大学物理 A** 资料整理进网站：**12 章、193 道题、49 个知识点**。题目来自 `题库/` 下的题库精选、作业题和参考答案；知识点来自 `知识点/` 下的 PPT、教学进度表和复习纲要，并补充了第 11 章（稳恒磁场）的详细讲解。

> **在线版（永久）：** <https://mori01130905-lang.github.io/physics-lab/>  
> 已部署在 GitHub Pages，平板直接打开即可，不需要电脑，也不需要服务器。
>
> **不想联网？** 用根目录的 `offline.html`：CSS、JS、字体、题库全部打包在一个文件里，拷到平板后用 Safari / Chrome 打开即可，不需要 Python，也不需要电脑一直开着。

## 一、现在就能用

### Windows

双击 **`start.bat`**。

脚本会自动启动本地服务器并打开浏览器。窗口中会打印：

- 本机地址：`http://127.0.0.1:8080`
- 平板地址：`http://你的电脑IP:8080`

### macOS / Linux

双击 `start.command`，或在终端运行：

```bash
python3 serve.py --open
```

### 平板（iPad / Android 平板）

1. 平板和电脑连接**同一个 Wi-Fi**。
2. 在平板浏览器打开启动窗口里显示的 `http://电脑IP:8080`（不是 `127.0.0.1`）。
3. iPad 可以点 Safari 的「分享 → 添加到主屏幕」，以后像 App 一样打开。
4. 如果打不开：
   - 确认电脑和平板在同一网络；
   - Windows 防火墙允许 Python 访问「专用网络」；
   - 电脑上的服务窗口不要关闭；
   - 地址要用 `http://`，不要用 `https://`。

> 本地服务器只是把页面发给平板，题目、进度和错题本都存在平板浏览器里。

## 三、配置 AI 批改

打开「设置 → AI 批改」。应用兼容任何 **OpenAI 格式的 `/chat/completions` 接口**。

### 推荐组合

| 用途 | 接口地址 Base URL | 文本模型 | 视觉模型 |
| --- | --- | --- | --- |
| 只批改文字答案（最省） | `https://api.deepseek.com/v1` | `deepseek-chat` | 留空 |
| 文字 + 手写识别 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | `qwen-vl-max` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` | `glm-4v-plus` |

填写自己的 API Key，点「测试连接」，看到「连接成功」即可。

> **关于手写识别**：只有配置了「视觉模型」，手写图片才会随批改请求一起发送。只配文本模型时，计算题请在文字框里补充关键步骤，或者使用「自评模式」。
>
> **关于跨域**：页面是直接从浏览器调用你配置的接口。实测 DeepSeek 和阿里云百炼兼容接口支持浏览器直连；如果某个服务商拦截跨域（CORS），请换用支持的服务，或在它前面加一层自己的代理。
>
> **关于 Key**：Key 只保存在当前浏览器 `localStorage`，不会上传到本应用之外的服务器。但它对能使用这台设备的人是可见的，建议使用单独的、限额的 Key。

### 批改严格度

- **宽松**：物理思路和结果基本正确就给分，单位小问题以提醒为主。
- **标准**：按步骤给分，最终结果错但方法对给部分分。
- **严格**：严格按评分点，关键步骤、单位、有效数字都扣分。

没有配置 AI 时，应用仍然完全可用：

- 选择题：本地判分；
- 填空题：本地比较可接受答案（支持数值容差、单位、等价写法）；
- 计算题：显示参考答案，进入「自评模式」，由你自己选择「基本做对 / 对了一部分 / 做错了」，结果同样进入进度和错题本。

## 四、平板书写

- 计算题答题区就是一块白板，直接用笔写。
- 检测到触控笔后会自动忽略手指/手掌触摸；也可以在工具栏关闭「防误触」。
- 点「全屏」把书写区放大到整个屏幕，适合写长过程。
- 支持压感、墨色/红色/蓝色、三档粗细、橡皮、撤销、清空。
- 除了手写，也可以：
  - 在文字框输入关键步骤；
  - 点「拍照 / 上传」上传纸面过程（最多 2 张）。
- **手写内容默认只在当前这次作答中使用，不保存到历史记录**；提交批改前不要刷新页面。答题进度和错题记录会保存。

## 五、题库导入

### 方式一：直接导入 JSON

「设置 → 题库 → 导入题库 JSON」。导入后会替换当前题库，校验不通过会列出具体错误。

### 方式二：把题库发给我

你可以把 Word / PDF / 图片 / Excel / JSON 发给我，我来整理成题库格式并替换。题目最好同时提供：

- 题干、选项、正确答案；
- 解析（越详细越好）；
- 所属章节和知识点；
- 计算题的参考答案和评分点（没有也可以，AI 会自己解）。

### 题库格式

完整模板见 [`assets/bank-template.json`](assets/bank-template.json)。最小结构：

```json
{
  "id": "university-physics-2026",
  "title": "大学物理",
  "subtitle": "2026 秋",
  "chapters": [
    {
      "id": "ch1",
      "number": 1,
      "title": "第一章 质点运动学",
      "intro": "本章简介",
      "knowledge": [
        {
          "id": "k1-1",
          "title": "位置、速度与加速度",
          "summary": "一句话概括",
          "formulas": [
            { "tex": "v=\\frac{dx}{dt}", "note": "速度是位置对时间的导数" }
          ],
          "points": ["Markdown 讲解，公式用 $...$ 包裹。"],
          "pitfalls": ["易错点。"],
          "examples": [
            { "question": "例题", "solution": "解答" }
          ]
        }
      ],
      "questions": [
        {
          "id": "q1",
          "type": "single",
          "stem": "题干，公式用 $...$。",
          "options": [
            { "id": "A", "text": "选项 A" },
            { "id": "B", "text": "选项 B" }
          ],
          "answer": ["A"],
          "explanation": "详细解析",
          "knowledge": ["k1-1"],
          "difficulty": 1
        }
      ]
    }
  ]
}
```

四种题型的 `answer` 写法：

```json
// 单选
{ "type": "single", "answer": ["A"] }

// 多选
{ "type": "multiple", "answer": ["A", "C"] }

// 填空：每个空可以有多个可接受答案
{
  "type": "blank",
  "blanks": [
    { "label": "最大高度", "answers": ["20", "20.0"], "unit": "m" },
    { "label": "总时间", "answers": ["4"], "unit": "s" }
  ]
}

// 计算：reference 是标准答案，rubric 是评分点（AI 会参考）
{
  "type": "calc",
  "answer": {
    "reference": "v(t)=2+3t^2，x(t)=2t+t^3，v(2)=14 m/s",
    "rubric": ["由 a=dv/dt 积分", "代入初始条件", "结果与单位正确"]
  }
}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 建议 | 全局唯一且稳定。进度按题目 id 记录；换题库时保留 id 可以保留进度 |
| `type` | 是 | `single` / `multiple` / `blank` / `calc` |
| `stem` | 是 | 题干，支持 Markdown 和 `$...$` 公式 |
| `options` | 选择题必填 | 字符串数组或 `{id,text}` 数组 |
| `answer` | 是 | 见上面的四种写法 |
| `explanation` | 建议 | 详细解析；做错时会展示 |
| `knowledge` | 建议 | 知识点 id 数组，用于错题归因和薄弱点统计 |
| `difficulty` | 否 | 1–5，默认 1 |
| `similar` | 否 | 静态「举一反三」题；不填时 AI 会生成 |
| `blanks[].unit` | 否 | 显示在输入框后面，不参与输入 |
| `answer.rubric` | 否 | 计算题评分点，能明显提升 AI 批改稳定性 |

公式用 `$...$`（行内）或 `$$...$$`（独立公式）；Markdown 支持标题、列表、加粗、引用、表格。

> 题库中的 `id` 不要随意改。改了 id，旧进度和错题就会对不上。

## 九、常见问题

**平板打不开地址？**  
确认同一 Wi-Fi、电脑服务窗口未关闭、Windows 防火墙允许 Python；用电脑的局域网 IP，不要用 `127.0.0.1`。部分校园网/酒店 Wi-Fi 会隔离设备，可以开手机热点让电脑和平板都连热点。

**AI 报 401 / 403？**  
Key 不对、过期，或没有该模型权限。重新复制 Key，确认模型名和平台一致。

**AI 报 404？**  
Base URL 或模型名不对。DeepSeek 要带 `/v1`；百炼兼容地址是 `/compatible-mode/v1`。

**AI 报 429？**  
请求太频繁或余额不足；等一会儿，或检查账户额度。

**AI 报跨域 / 无法连接？**  
该服务商不允许浏览器直接调用。换 DeepSeek 或百炼，或者自己加代理。

**手写内容 AI 没看到？**  
没有配置视觉模型。设置里填 `qwen-vl-max` 或 `glm-4v-plus` 一类的视觉模型；也可以同时写文字答案。

**刷新后手写没了？**  
手写只在当前作答内存中，提交前不要刷新。文字进度和错题记录会保存。

**AI 批改准吗？**  
AI 可能误判，尤其是字迹潦草或跳跃步骤。结果页会同时给出参考答案，请以标准解法为准。配置「评分要点」能明显提高稳定性。

**题目/解析有错误？**  
题库内容由你提供的原始资料决定；AI 生成的「举一反三」也可能出错，建议核对后再练。
